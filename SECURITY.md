# Security Policy

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

The Katalyst.SMT team takes software and verification security seriously. If you discover a security vulnerability—such as an SMT solver bypass, memory exhaustion vector, or cross-site scripting vulnerability—please report it responsibly.

### Disclosure Process
1. **Do not create a public GitHub issue.**
2. Send an email to `security@katalyst-smt.org` or open a private GitHub Security Advisory.
3. Include:
   - Description of the vulnerability and attack vector.
   - Minimal reproduction topology JSON.
   - Potential impact and affected versions.
4. The security response team will acknowledge receipt within 48 hours and provide a coordinated disclosure timeline.
